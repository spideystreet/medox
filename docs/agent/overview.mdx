L'agent servi en production est une boucle d'outils dans `src/medox/api/agent.py`. Le modèle est appelé via le SDK Mistral (`mistralai`). Tant qu'il demande un outil, le serveur l'exécute et renvoie le résultat. Au plus six tours.

La clé est celle du serveur : `MISTRAL_API_KEY`, sinon `OPENROUTER_API_KEY`.

```python
TOOLS = [search_drug, find_generics, check_interactions, get_rcp]
```

Avant la réponse finale, `safety.warning_prefix` préfixe l'avertissement si un outil a renvoyé une contre-indication ou une association déconseillée.

Le prompt impose :

- appeler `check_interactions` avant une recommandation
- ne pas donner de conseil médical direct
- citer le code CIS
- rapporter le niveau de contrainte ANSM renvoyé par l'outil
- ne pas compléter hors outil si aucune interaction n'est trouvée
